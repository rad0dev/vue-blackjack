# Vue Blackjack

A browser-based Blackjack card game built with Vue.js. Features fully playable card game with standard Blackjack rules with optional user authentication.

## Live Demo

[Play the game](http://vue-blackjack.s3-website.eu-central-1.amazonaws.com/)

## Tech Stack

- Vue.js
- Deployed on AWS S3 (static hosting)

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```
